# Mamba3 Rotation Audit

# 《Active but Minimally Read Out: Auditing Mamba-3's Complex-Rotation Pathway in Subject-Independent EEG Emotion Recognition》

Mamba3 Rotation Audit investigates whether Mamba-3's input-dependent complex-rotation pathway materially contributes to subject-independent EEG emotion recognition. The project provides controlled rotation ablations, intervention-based diagnostics, and synthetic phase-sensitive experiments under a subject-independent evaluation protocol.

This paper is currently under review at ICASSP 2027.
